Share Joysticks, 3D Printers, Laser Engravers & Any USB Device Over Your Network.

USBAnywhere exposes remote USB hardware—gamepads, DualSense/Xbox controllers, 3D printers, laser cutters (LightBurn/GRBL), audio interfaces, and storage—over TCP/IP and VPN links as native local devices. Built on a direct C#/.NET 9 Windows VHCI IOCTL engine, WHQL-signed drivers, and an on-demand TCP/3241 control plane.

01 // SYSTEM ARCHITECTURE

Engineered for Reliability Under Load

01 / IOCTL_ENGINE

Direct Windows VHCI IOCTL

Communicates directly with the WHQL-signed usbip2_ude kernel device handle via Win32 DeviceIoControl, eliminating process-spawn overhead and stdout regex parsing.

02 / CONTROL_PLANE

On-Demand TCP/UDP 3241

Automatic LAN/VPN server discovery on UDP 3241 and serialized per-busid LIST / BIND / UNBIND / STATUS control over TCP 3241 with immediate host release on client detach.

03 / KERNEL_HARDENING

High-Throughput & SBC Ready

Includes Linux usbip-host and RPi/OrangePi dwc2 kernel patches for composite endpoints, isochronous audio/video, CNC/laser controllers, and DualSense HID polling.

Joysticks & Gamepads

Low-latency HID passthrough for DualSense, Xbox, flight sticks, racing wheels, and VR trackers.

3D Printers

Direct USB/Serial access for Prusa, Creality, Marlin/Klipper boards, and slicer/firmware flashing.

Laser Cutters & Engravers

Stable streaming for LightBurn, GRBL, Ruida/CH340 controllers, and CNC workshops from another room.

Any USB Peripheral

Webcams, DACs/audio interfaces, scanners, license dongles, smartcards, and USB storage drives.
